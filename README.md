# gautama

Static Astro site for gautama’s painting and mixed media work.

## local development

```sh
npm install
npm run dev
```

Run the production checks before publishing:

```sh
npm run check
npm run build
```

The build writes the deployable site to `dist/`. Pushes to `main` deploy it through GitHub Pages; see [DEPLOYMENT.md](DEPLOYMENT.md) for the one-time GitHub and Cloudflare setup.
